# Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Features

- Play Rock, Paper, or Scissors against the computer
- The computer randomly selects its move
- Tracks the player's wins and the computer's wins
- Displays whether each round is a win, loss, or tie
- Reset the scores and start a new game
- Dark-themed interface with colored result messages

## How to Play

1. Open the game in your web browser.
2. Select Rock, Paper, or Scissors.
3. The computer will choose its move automatically.
4. Check the result and the updated scores.
5. Select **Reset** to clear both scores.

## Run Locally

1. Download or clone this repository.
2. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

No additional installation is required.
